# Vocab design mockups

Approved visual direction for the frontend:

- `homepage.html` — approved home dashboard.
- `dictionary.html` — proposed dictionary layout.
- `training.html` — training page with multiple-choice and manual-input modes.
- `training-result.html` — completion screen for strong and weak results.
- `auth.html` — login and registration states.
- `profile.html` — personal account, learning preferences, and security.

The mockups are HTML fragments intended as visual references. Shared palette:
violet primary, coral accent, lime primary-action highlight, and pale violet
surfaces. Both layouts include responsive rules for narrow screens.
